## Installation

1. Install node modules:
npm install

2. Dowload Visual Studio Installer. Install C++ Based programms with additional Windows 10/11 SDK and MSCVC version 143

3. Dowload and install Rust:
https://rustup.rs/

4. Run project:
npm run tauri dev
